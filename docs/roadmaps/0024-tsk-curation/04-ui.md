# 0024 · UI

New components or variants below are **proposals** (CLAUDE.md: propose in chat first, prefer a prop/variant). Final names go into `Components.md` with the row that builds them.

## Hover card with original text

- `GetVerseCrossReferenceTexts` gains per verse `original: { language: "hebrew" | "aramaic" | "greek", text }` (plain surface words joined, no morphology). Same source as `GetChapterOriginals`.
- `PassagePreviewCard` gets an optional `originals` prop. From `md` up the card widens (token width, e.g. `w-160` instead of `w-80`; the `CARD_WIDTH` constant in `CrossReferenceList` follows) and shows two columns, German left, original right; below `md` the original sits under the German. Hebrew/Aramaic gets `dir="rtl"`, `lang="he"`/`"arc"`, Greek `lang="grc"`, in the font tokens the "Grundtext" panel already uses. Ranges show verse numbers in both columns.
- The comment of a curated link (if any) shows under the texts, above the fold, muted.

## Reader display (everyone)

- `CrossReferenceList` (both variants) receives `rating`, `comment`, `origin`, `word` per reference. Highlighted refs come first with a marker (star icon + `font-medium`); added refs show a small "+" marker; hidden refs are not in the list.
- Toggle "Nur hervorgehobene" in the TSK side panel header, stored per browser (`uw.tsk.onlyHighlighted`, `localStorage` in try/catch), default off.
- Word links: a linked ref shows next to the word in the TSK panel ("„Anfang“ · Spr 8,22"), and the word box (`WordDetailService`) lists the refs linked to *that* word first, then the remaining verse refs.

## Curation (logged-in)

- A pen icon per ref in the TSK side panel opens a small popover editor (proposal: `CrossReferenceEditor`): three-state Hervorheben / Neutral / Ausblenden, comment field with counter (500), "Wortverknüpfung lösen" when linked. Maintainers save directly; others see "Vorschlag senden" and afterwards a `StatusBadge` "Vorschlag offen".
- "Querverweis hinzufügen" at the end of a verse's list: a reference field parsed by `api/references/parse` (German, e.g. "Röm 8,28-30"), preview of the text, optional comment.
- A curate-mode switch (curators only) shows hidden refs greyed with "Einblenden".

## Link mode

- Switch "Verknüpfen" in the TSK panel header (logged-in). In link mode each ref gets a checkbox; click toggles, Shift-click selects a run, Ctrl/Cmd-click toggles one. A ref or the selection is dragged (native HTML5 drag and drop, no new dependency) onto a word of the **source** verse in the reader; the target word gets `bg-mark-note`-like feedback (proposal: new token `--uw-mark-link`). Dropping on a word with Shift held extends to a word range from the last dropped word.
- Touch and keyboard: select refs, then tap/Enter on a word ("Auf Wort legen" hint bar with Abbrechen). Esc clears the selection.
- Hovering or focusing a ref still opens the hover card; the card is suppressed only while a drag is in progress.
- Linked refs are shown under their word in the panel; unlinked ones under "Ohne Wort".

## Review page `/edit/tsk` (maintainers)

Page "TSK-Vorschläge" in the maintainer menu: pending proposals grouped by source verse, each row with the link, current vs proposed state (rating, comment as word diff via `lib/revision/wordDiff`, word quote), author and date; Annehmen / Ablehnen (reason ≤ 500). Accept and reject write the admin log (`tsk_proposal_accepted` / `tsk_proposal_rejected`).
