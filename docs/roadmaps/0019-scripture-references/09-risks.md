# 0019 · Risks

- **Users who type English style get a different result than they meant.** In German citation style `Offb 2,1-5; 7` is chapter 7 and `Joh 3,16,18` is an error. Someone used to `;`/`,` as verse list separators lands elsewhere. The card always shows the formatted result before Enter (`Offb 2,1–5; 7`), and the `Joh 3,16,18` error hint suggests `3,16.18`.
- **Abbott-Smith may cite LXX Psalms in LXX numbering.** STEP marks them as `Psa.88.12` without saying which counting; the English → Hebrew map then lands one psalm off for some LXX-context citations. Not detectable from the tag. Accept for now; the coverage report (0019.10) lists Psalm references so a sample can be checked by hand. Signal to act: users report wrong Psalm previews.
- **Short aliases cause false positives once prose is scanned.** German `Am`, `Hos`, `Mal`, `Mi` are ordinary words, and the short English aliases in `BibleBook.AllBooks` (`Co`, `de`, `so`, `mr`) survive only in the `Legacy` profile. The scanner uses only `Osis` (`Book.` + digit). Scanning German prose is out of scope exactly because of this; a future scanner needs its own stricter profile.
- **Changing `Jud 3` changes MCP behaviour.** Today `get_passage("Jud 3")` returns nothing useful (Jude has one chapter), after 0019.4 it returns Jude 3. Strictly an improvement, but agent prompts or saved MCP calls that relied on whole-chapter semantics for single-chapter books would change. Search `assets/agent-prompts` for single-chapter book references before merging 0019.4.
- **Parse endpoint per keystroke and the anonymous rate limit.** The overlay calls `references/parse` on every submitted (debounced) query in addition to the verse search, doubling anonymous requests from search. If `RateLimiting:Enabled` limits are tight, searchers hit 429 sooner. Mitigation: parse is cheap and cached (`staleTime: Infinity`); if needed, exempt the endpoint from the limiter or fold the parse into `search/verses` later.
- **Truncated lexicon text can now drop a link at the end.** The 600/300-character cut never splits a reference, so a text may end slightly earlier than today. Visible but harmless; the "(gekürzt)" note stays.
- **No STEP prose in fixtures.** Tests must use reference tags and invented sentences only. A fixture with copied lexicon text would violate the "never redistributed" rule in `CLAUDE.md`; reviewers check `tests/**/References/` for it.
