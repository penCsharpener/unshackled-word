# 0027 · UI

## Reader: side panel mode "Ähnliche Verse"

- `SidePanelMode` gains `"similar"`; `SIDE_PANEL_MODES` = `tsk → original → similar → off`, so `G` cycles through it. Rail icon and label `bible.sidePanel.verseSimilar` ("Ähnliche Verse zu V. {verse}" / "Similar verses to v. {verse}").
- Per verse, up to 10 hits (with "mehr" expanding to 30), each row:
  - reference (link, same drag/hover behaviour as TSK rows; hover card shows the Elb1871 text and the original text),
  - the Elb1871 text of the hit with the German words linked to the shared Strong's highlighted (0027.4f),
  - chips for shared original words (lemma, transliteration, gloss), with matched phrases first ("ῥομφαία δίστομος ὀξεῖα"),
  - a quiet score bar (relative to the verse's best hit, no raw number).
- Empty state: "Keine ähnlichen Verse (seltene Wörter fehlen oder Berechnung steht aus)".
- Endpoint: `GET api/elberfelder/similarVerses/{bibleBookId}/{chapter}?limit=10` and `GET api/elberfelder/similarVerses/verse/{hebRefId}` (30, for "mehr").

**Component:** the hit list is a different shape from `CrossReferenceList` (explanations, highlights, no curation). Propose in chat before 0027.3f whether it becomes a `variant` of `CrossReferenceList` or a new `SimilarVerseList`; register the result in `Components.md`.
