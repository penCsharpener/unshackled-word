# 0030 · Risks worth naming before starting

- **AI roots are shown before anyone checks them.** This was decided ([02-decisions.md](02-decisions.md)), and learners will see wrong splits (παρά read into παραβολή's family, or a Hebrew noun under the wrong homograph root). The KI badge, the strict validator and the spot-check in 0030.8 limit this. If the spot-check lands under 90 %, run prompt v2 before the seed commit rather than shipping the first run.
- **Parent roots are only as complete as the maintainer makes them.** μαρτυρία, μάρτυς and μαρτυρέω stay three families until someone sets `ParentRootId` by hand, because this roadmap has no AI for parents. A root course built on wide families would group a few roots and leave most of them flat. When that course is planned, add a parent mode to `vocab-root` (deferred here), with the same badge and validator approach.
- **Wide families can teach false relatives.** Folk etymology (a παρά that is no preposition, Hebrew roots that look alike) is far more likely at the deeper level than when stripping prepositions. Parents are manual-only for that reason, and the path `μαρτυρία → μαρτυρέω` stays visible wherever a sub-root is listed.
- **Abbott-Smith hyphens are not a complete compound marker.** 1,491 of 5,405 Greek entries are hyphenated, so some compounds have no hyphen and a few hyphens mark something other than a preposition. The prefill writes only full matches against the closed preposition table. The AI covers the rest, and `prefill` rows stay correctable.
- **Hebrew homograph roots are ambiguous by nature.** The verb rule numbers homographs by key order, which need not match the lexicon's I/II. Merging two `VocabRoots` rows means repointing `VocabStrongsRoots`. 0030.5 needs no merge action, but if the maintainer starts merging by SQL, that is the signal to build one.
- **An import must not undo maintainer work.** The seed importer never overwrites `manual` with a non-manual row, and 0030.7 tests exactly that. A bug here would silently undo corrections on every self-hosted install.
- **Entries with keys that disagree.** The root comes from the main key. An entry merged from two keys with different roots shows one of them with no hint. The data-quality check in 0030.7 makes these visible. Until then they are invisible.
