- On phone width the three columns collapse into one line under the lemma: `σύν + ἐπί · μαρτυρέω (G3140)`.

## Family filter

- URL parameter `root=<VocabRootId>` on both lists, kept like the other list params. A chip "Wortfamilie: μαρτυρέω ×" clears it.
- The filter lists every active entry of the course whose root is that id, the root's own entry first, then by rank.
- When the root has sub-roots (through `ParentRootId`), a toggle "mit Unterwurzeln" (default on) adds them, grouped by sub-root: μαρτυρέω, then μαρτυρία, μάρτυς … When the root has a parent, a link "↑ πόρος" opens the wider family.
- The editor list adds the filter "ohne Wurzel" (main key without a root row) and the counts by origin.

## Detail page (`/vocab/:id`)

A "Wortfamilie" block: prefixes + root, then the other members of the family (lemma, meaning, rank), at most 12 with a "alle anzeigen" link to the filtered list.

## Trainer card

The back of the card shows one line under the meaning: `σύν + ἐπί + μαρτυρέω`. A simple word shows nothing. It comes from the `VocabCard` DTO (new optional `root` object) and is not part of answer checking.

## Editing (`/edit/vocab/:id`, Admin/Maintainer)

A "Wurzel" section on `VocabEditorPage`: a prefix picker (closed preposition list, ordered), a root search (vocab entries of the same track, or for Hebrew free letters plus an optional verb key), a "Einfaches Wort" toggle, and save, which sets `manual`. "Wurzel neu anlegen" for a Hebrew root with no verb. "Übergeordnete Wurzel" picks a parent for the current root (same track, cycle check), shown with the path `μαρτυρία → μαρτυρέω`. Each save goes into `VocabEntryChanges` with a new kind `root`, without a `ContentVersion` bump.
