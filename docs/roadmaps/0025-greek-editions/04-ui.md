# 0025 · UI

## Word detail box (Greek readings)

Per `OriginalReading`, new optional field `editions` (omitted when the word is in all main editions without shift, so 92 % of words carry nothing):

```ts
interface ReadingEditions {
  present: EditionRef[];   // sorted by catalog Sort
  missing: EditionRef[];   // main editions only
}
interface EditionRef { code: string; kind: "edition" | "translation" | "manuscript" | "version" | "unknown"; shift?: number; shiftRaw?: string }
```

Rendered as a small section "Textausgaben" under the morphology of that reading, via a new component **`EditionList`** (to be confirmed in chat and registered in `Components.md`):

```
Textausgaben   ● TR  ● Byz           fehlt in: NA28 NA27 Tyn SBL WH Treg
               ● TR  1 Wort später   (shift)
               + Sinaiticus (01)     (non-main, muted)
```

- Chips use existing badge tokens; present = neutral, missing = muted/struck, non-main = muted with kind label.
- Hover/tap on a chip: full name and year from the catalog (`Name`, `Year`); English names from i18n by `code`.
- `shiftRaw` (cross-verse) shows as "andere Stelle (14,24)".
- A one-line explanation ("Ausgabe = gedruckter Grundtext, keine einzelne Handschrift") behind an info icon.

## Grundtext panel (`OriginalVerse`)

- `VerseMappingOriginalWord` gains `editionCodes?: string[]` (present main codes, omitted when in all main) and `hasShift?: boolean`.
- Words not in all main editions get a subtle underline (dotted, token `--uw-mark-variant`, proposed) with a tooltip "nur in TR, Byz" / "fehlt in WH". Words with only a shift get no mark (too noisy; they show in the word box).

## Edition filter

- Reader settings (where the Grundtext toggle lives) get a select "Ausgabe": `Alle` (default) + the eight main editions in catalog order.
- With an edition picked, Greek words whose `editionCodes` (omitted = all) lack it are hidden in the Grundtext panel; a muted line at the verse end says "2 Wörter ausgeblendet (nicht in NA28)". Order is not changed.
- Stored in `localStorage` (`uw.reader.greekEdition`), applies to NT chapters only; the select is disabled in OT chapters.
- The catalog comes from a public, long-cached endpoint `GET api/greekEditions`.
