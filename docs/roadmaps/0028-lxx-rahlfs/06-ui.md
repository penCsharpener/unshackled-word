# 0028 · UI

Components: check `Components.md` first, and propose any new component in chat before building it. Use tokens only and support German and English.

## Side panel mode "LXX" (reader, OT only)

- `SidePanelMode` gains `"lxx"`. `SIDE_PANEL_MODES` becomes `tsk → original → lxx → similar → off` (`G` cycles, the mode is stored in `uw.sidePanel`), but the mode is hidden in NT chapters. The rail heading is "Septuaginta (Swete)", with a muted line: "Griechischer Text nach Swete, Verszählung nach Rahlfs".
- Each Elb1871 verse shows its LXX verse, with the Rahlfs reference as a small label whenever it differs (e.g. "Jer 32,1 LXX"). Additions follow their `AfterHebRefId` verse in a muted frame titled "Zusatz der LXX". In Daniel, an `og`/`th` toggle (Theodotion by default) is stored in localStorage as `uw.reader.lxxForm`. A verse with no LXX text shows "In der LXX nicht vorhanden".
- Words render through `OriginalVerse variant="margin"` with a new `language: "lxx"` value. Prefer a prop over a new component. Untagged words are plain text. Tagged words get the hover card with lemma, gloss and parse (`WordInfoCard`) and link to `/bible/strongs/{id}`.
- **Hover link (0028.10f):** hovering an LXX word marks its linked Hebrew words (when the original panel is open) and their German renderings through the existing `pillWords` marking (`bg-mark-linked`).
- **Maintainers only:** proposed tags show with a dotted underline and "Vorschlag" in the card.

## Strong's page

The occurrences list (`GetStrongsOccurrences`) gets a corpus switch: "NT", "AT (hebr.)", "LXX". The LXX list shows the Rahlfs reference, the Greek verse with the word marked, and the Elb1871 verse it maps to. It counts confirmed tags only, with a muted line "n weitere Vorkommen noch ungeprüft" for maintainers.

## Review page `/edit/lxx` (Admin/Maintainer)

- On the left, books and chapters with open-proposal counts. On the right, a verse table: Greek word | lemma | Strong's | parse | Hebrew words | confidence.
- Every cell can be edited. Lemma and Strong's use a TBESG search `Select`, and parse uses a code field with live validation through the parser (0028.7).
- Buttons "Vers bestätigen", "Vers verwerfen", "Kapitel bestätigen (sichere)" and "KI neu für Auswahl".
- The verse's Hebrew is shown above, so a link can be set by clicking a Hebrew word.
