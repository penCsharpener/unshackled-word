# 0022 · UI

Routes are German first like the rest of the SPA, with English aliases and texts in both i18n files. New components are proposed in chat before they are built and registered in `Components.md`. Tokens only.

## Public

- **`/vokabeln`**: track toggle NT/AT, a frequency list (rank, lemma, dictionary form, top meanings, occurrences, play button, an "ungeprüft" badge when `ReviewedAt` is null), search by lemma, transliteration or German. Mobile: one column of cards.
- **`/vokabeln/:id`**: lemma, form, audio, Strong's keys (link to the existing Strong's page), accepted meanings, and the full renderings table with counts and share bars (Elberfelder 2027 vs. Elb1871 part), plus sample verses that link into the reader.

## Studying (signed in)

- **`/lernen`**: two course cards with known/due/new counts and **text coverage** ("Deine Wörter decken 62 % des NT-Textes ab"), and a start or continue button. Anonymous visitors see the cards with a login hint.
- **`/lernen/:course`**: the session. One card per screen: introduction, MC, reverse MC, listening, verse context, typing. After each answer: verdict, correct answers, strength bar (moved / held / dropped), one verse with the word highlighted. At the end: a summary of what moved. Keyboard: 1–4 pick, Enter continue.
- **Typing card**: the dictionary form (or the lemma) is drawn as letter boxes per group, with the separators (`, -`) printed between them, so `μέσος, -η, -ον` shows `[_____], -[_], -[__]`. The cursor jumps to the next group when one is full. This is the Lexio 0022 "character boxes" pattern.
- **"Geändert" notice**: on `/lernen` and at the start of a session, "3 deiner Wörter wurden überarbeitet" opens a list. Each item shows before/after (meanings, form, merge/split note) with "Weiterlernen" and "Zurücksetzen", plus "Alle weiterlernen". It never blocks a session.
- **Script keyboard** (port of Lexio 0049, `simple-keyboard`, needs approval): Greek and Hebrew layouts, RTL input for Hebrew, physical keyboard mapping, no marks needed.
- **Settings**: disable quiz types (at least one MC type stays on).

## Maintainer ("Wartung" > "Vokabeln")

- Jobs: generate lexicon, refresh renderings, derive meanings (dry run → apply), agent forms. Each shows its last run time.
- **Vocab editor `/wartung/vokabeln/:id`**: dictionary form with its origin, meanings (reorder, accept/unaccept, pin, add manual, delete manual), the renderings table beside it for reference, Strong's keys (move a key to another entry, split it into a new entry), audio (upload, record, play, delete), "geprüft" toggle, merge into another entry, retire, delete. Before saving a learning-relevant change, the editor says how many learners have a card on the entry ("12 Lernende werden benachrichtigt"). It does not block the change. A list view with filters: unreviewed, no audio, form missing, form from agent, rank range.
