# 0029 · Risks worth naming before starting

- **German case tags would teach wrong grammar.** `Elb1871Morphology` marks 125,193 nouns nominative and only 2,361 accusative; in John 3:16 "die Welt" and "seinen eingeborenen Sohn" (both accusative) are tagged nominative. A `dt.Kasus` search would confidently list wrong verses. It is withheld; the signal to add it is a re-tagged or corrected `Elb1871Morphology` whose noun case distribution looks like German prose (accusative far above 2 %). Spot-check `dt.Numerus` and `dt.Geschlecht` the same way in 0029.6 before shipping them.
- **Labels live in two places.** The parser needs the German labels on the server, the reader shows them from `de.ts`. If they drift, a user types what the UI shows and gets `unknownValue`. The 0029.2 test that reads `de.ts` is the guard; it must fail loudly, not skip, when the file moves.
- **A Latin word can be read the wrong way.** `logos` is a transliteration, `Licht` is German, but some words are both. The chip shows the reading for every slot and `Lemma:` / `dt.Wort:` force it; if users still trip over it, the fix is a visible toggle on the chip, not a smarter guess.
- **Grammar without a lemma is the expensive case.** `Wortart:substantiv` touches 29,467 Greek nouns (proper names not counted) and far more Hebrew words, and every page also computes totals and book counts. 0029.1 and 0029.5 measure the heavy queries with `EXPLAIN ANALYZE`; if counts dominate, cache totals per normalized query (FusionCache, like other read endpoints) rather than dropping them. Rate limiting for anonymous users already applies.
- **Hebrew root-only filtering hides prefixes.** `HTd/Ncmsa` (article + noun) decodes `Status` from the root as absolutus; "determiniert" only comes from Aramaic emphatic state. A reader searching `Status:determiniert` for "with article" gets a much smaller set than expected. The cheat sheet says so; prefix/suffix filters are deferred.
- **Deponents are merged into voice.** `Diathese:pass` includes Robinson `O` (passive deponent, 326 of the 1,706 aorist passives). That matches the word detail popover but not every grammar textbook; `Code:` reaches the raw distinction. Revisit if a `Deponens` value is requested.
- **Unmapped words still count.** About 170,000 Greek mappings exist; an original word without a German rendering (articles, particles) is a hit with no German highlight. This is correct, but the hit must say "nicht übersetzt" instead of looking like a highlighting bug.
- **Hits show Elb1871, not the reader level.** A reader on a revision level sees base text in search results. Acceptable for now (mapping is on Elb1871); the signal to solve it is a revision with its own mapping for a substantial share of verses.
- **A forgotten query keeps marking.** The query survives reloads by design, so a reader may come back days later to marked words without remembering why. The reader chip is always visible while marks are on and names the query; it must not be hideable. If confusion shows up anyway, expire the stored switch (not the query) after a day.
- **Marks on revision text can be incomplete.** Positions are Elb1871; on a reader level with a variant, a word without `BasePositionInVerse` is not marked although the verse counts as a hit. The chip's count is per chapter from the base text, so it can be higher than the visible marks; the verse search marks (0029.10) use the reader level and do not have this gap.
- **German number tags are weak outside nouns (checked 0029.7).** Only 974 of 108,616 determiners and 485 of 9,122 adjectives are tagged plural ("die" is almost always singular feminine), and unmarked noun plurals ("die Himmel", Gen 1:1) are tagged singular. `dt.Numerus`/`dt.Geschlecht` are reliable on nouns only; the cheat sheet (0029.9) recommends combining them with `dt.Wortart:Substantiv`. The German lemma also lumps some verb forms in ("ich liebe" under Liebe).
