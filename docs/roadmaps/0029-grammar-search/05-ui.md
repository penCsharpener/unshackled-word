# 0029 · UI

## Search overlay

- **Grammar mode.** A query is a grammar query when one token is `key:` with a vocabulary key (with or without `dt.`). In the Grundtext tab such a query shows the grammar result instead of the lemma cards; in the Verse tab it shows a one-line hint "Grammatiksuche – im Reiter Grundtext anzeigen" with a button that switches tabs.
- **Slot chips** above the result, one per slot: how the word was read ("agape → ἀγάπη G26", "Liebe → deutsches Wort", "beliebiges Wort") and the filters in words ("Nominativ", "nicht Partizip", "dt. finit"). An error marks its token in the chip row ("Tempus:p ist mehrdeutig: Präsens, Perfekt, Plusquamperfekt"; clicking a candidate replaces the token).
- **Summary line and book chart:** "36 Vorkommen in 32 Versen" plus the existing `BookBarChart` per book, clicking a bar filters by book (as in verse search).
- **Hits:** verse reference, Elb1871 text with the German words of each match highlighted, below it per match the original form (`font-original`, RTL for Hebrew) with lemma and the decoded grammar in words ("ἀγάπη · Substantiv, Nominativ Singular feminin"). A match without German rendering shows the original line only. "Mehr laden" pages like verse search. Enter on a hit opens the verse in the reader.
- **Component proposal (chat first):** extend `VerseHitList` with an optional per-hit `details` slot for the original lines, rather than a new hit list.

## Autocomplete

- Works on the token under the cursor, from the vocabulary (`useGrammarVocabulary`, fetched once, `staleTime: Infinity`), instantly and without a request:
  - after `Kasus:` or `Kasus:nom` → values whose folded label starts with the typed prefix, "Nominativ" first;
  - a bare prefix of 3+ letters that starts a value → the keyed form (`aor` → "Tempus:Aorist", `mas` → "Geschlecht:maskulin");
  - a bare prefix that starts a key → the key with colon (`Kas` → "Kasus:").
- Values show their language ("nur Griechisch", "nur Hebräisch") so `Tempus:` in an OT search does not look broken.
- Later rows add: lemma suggestions for word tokens (existing `useSourceWordsLookup`, debounced; accepting inserts the Strong's number, the chip shows the lemma) and counts from the facets endpoint (values without occurrences for the slot are dimmed, counts right-aligned).
- Keyboard: ↑/↓ moves, Tab or Enter accepts (Enter without an open list submits), Esc closes the list and keeps the overlay open. ARIA combobox pattern on the `TextField`.
- **Component proposal (chat first):** a `suggestions` prop on `TextField` that renders a new `SuggestionList` listbox (positioned under the field, design tokens only), reusable for other fields later. Register in `Components.md`.

## Highlighting in the reader

- **The query stays.** Input and tab are kept in `localStorage` (`uw.search.query`, `uw.search.tab`) and restored on open and after reload. Esc, closing the overlay and following a hit keep it; only the clear button (×) in the field, or deleting the text, removes it.
- **Switch "Treffer im Text markieren"** (existing `Switch`) under the field, stored as `uw.search.mark`. It works without using the result list: type, switch on, close.
- **Marks:** while on and the query is valid, `ChapterPage` loads the chapter matches for the open chapter (and again on every chapter change) and marks the German words with a new design token `bg-mark-search`, distinct from the hover marks `bg-mark-same`/`bg-mark-related` and combinable with their underline. `OriginalVerse` marks the matched original words. Revision variants are marked through `BasePositionInVerse`; words of a variant without a base position are not marked.
- **Reader chip** (top of the chapter, next to the side-panel controls): "Markiert: agape Kasus:nom · 1 Treffer" with ‹ / › to the previous/next chapter with a hit (neighbours endpoint, disabled when there is none) and × to switch marking off (the query stays). Clicking the query text opens the overlay with it. In a chapter without hits the chip says "Keine Treffer in diesem Kapitel" and keeps the arrows.
- **Invalid or ambiguous query:** no marks, the chip says "Suche unvollständig" and opens the overlay on click.
- Component proposal (chat first): the chip as a variant of an existing chip/badge (`StatusBadge`) rather than a new component.

## Help

A "?" button next to the search field in grammar mode opens a short cheat sheet generated from the vocabulary: keys with aliases and values, three example queries, and the `dt.` prefix. Clicking an example fills the field.

## Strong's page

- A "Formen" block on `/strongs/:id` with one row per key that occurs for the lemma (`Kasus: Nominativ 36 · Akkusativ 33 · Dativ 29 · Genitiv 18`), from the facets endpoint.
- Clicking a value filters the occurrence list (`grammar` parameter) and adds a chip to the existing "Aktive Filter" row; the filter is kept in the URL (`?grammar=Kasus:nom`) like the book and rendering filters.
- A slot chip in the overlay links to the Strong's page with the slot's filters applied.

## i18n

All new strings de and en. Value labels come from `grammar.*`; missing ones (Präteritum, finit) are added in both languages.
