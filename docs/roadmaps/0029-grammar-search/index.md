## Status (2026-11-26)

Implementation started 2026-11-26 on `feature/morphology-search`. Numbering continues from `feature/lxx` (0.13.18, migrations up to 0053): this roadmap is version 0.14.0 with 0029.1, then a build number per row; migrations `0054_GrammarSearchGreekIndex.sql` (0029.1) and `0055` (Hebrew index, 0029.6). `ExpectedMigration` follows.

**0029.1 (Greek grammar search, backend) done, version 0.14.0, migration 0054.** Measured: `agape Kasus:nom` 36 words / 32 verses (Matt 24:12 first), `Tempus:aor Diathese:pass` 1,706 / 1,451, `Kasus:nom` without lemma 46.6 ms (bitmap scan on `IX_StepGreekWords_Morphology`, no further index needed). Deviations:

- Routes live under the `elberfelder` group like the other searches: `api/elberfelder/search/grammar…` (design files updated).
- `StrongsLexiconIndex`/`SourceFormIndex` are WebApi types, so word reading sits behind `IGrammarWordReader` (Application) with `GrammarWordReader` in the endpoint folder; transliteration must match exactly (the lexicon search is prefix-based).
- DI in the existing `ServiceCollectionExtensions`, not per-slice `EndpointServices.cs`.
- `LxxRefId` → `HebRefId` uses a left join with fallback to the Greek key (as `StrongsStatsRepository`); an inner join lost one verse.
- `Code:` without `*` is an exact match; `books` counts verses; `original.form` is the printed Greek (may carry punctuation).
- `dt.` keys are typed but disabled (`GermanKeysEnabled = false`) until 0029.7.
- Open: two Application test failures in the agent-prompt tests (`AgentPromptProviderTests`, `AgentPromptExampleTests`) are outside this change and not yet investigated.

**0029.2 (chapter matches and neighbours, backend) done, 0.14.1.** `chapter/40/24?q=agape Kasus:nom` → verse 12, position 9, ~30 ms warm; `neighbours` for Matt 24 → no previous, next John 17. Decisions: `total` counts matched original words in the chapter; in a hit verse every candidate word of every slot is marked (the distinct-word rule only decides whether the verse is a hit); `originalWordIds` are `StepGreekWords.Id` as used by `OriginalVerse`. Frontend row 0029.2f open.

**0029.3 (vocabulary endpoint) done, 0.14.2.** `api/elberfelder/search/grammar/vocabulary` is built from `GrammarVocabulary` (no second list); `GrammarVocabularyLabelTests` compares every value label with `de.ts` (exact) and `en.ts` (case-insensitive) and fails naming category and key. Languages include `aramaic`; `dt.` keys are not listed while `germanKeysEnabled` is false; `Code`/`Strong`/`Lemma` are `freeValue`.

**0029.5 (facets endpoint) done, 0.14.3.** `api/elberfelder/search/grammar/facets` counts words per value with one `GROUP BY "Morphology"` per request, folded in C#; the slot's own filter on the key is ignored. `agape Kasus:` → Nominativ 36, Akkusativ 33, Dativ 29, Genitiv 18; no lemma ~50 ms. Empty values (`Kasus:`) are accepted only by this endpoint (`allowEmptyValue`). Counts are words in `StepGreekWords`, without the verse intersection of other slots. `Sprache`/`Code` are not facetable. Frontend row 0029.5f open.

**0029.6 (Hebrew/Aramaic, backend) done, 0.14.6, migration 0055.** `H1254 Stamm:qal` 39 words in 33 verses (the roadmap said 33 words; corrected: the first count missed roots after a prefix segment such as `HC/Vqw3ms`), Gen 1:1 first, `bara`/`ברא` identical; `Sprache:aramäisch` 4,827 words; `Stamm:piel` ~90 ms; `Wortart:substantiv` over both languages ~320 ms. **0029.7 (German side, backend) done, version bump pending.** `dt.` keys `Wortart`, `Tempus`, `Modus`, `Verbform`, `Person`, `Numerus`, `Geschlecht`, `Steigerung`, `STTS` (free tag, `*` wildcard) and `Wort`; `dt.Kasus` stays 400 `unknownKey`. A Latin token that is no Strong's number, script form or exact transliteration is read as German lemma (`readAs: "german"`, `germanLemma`); `Lemma:`/`Strong:` never fall back, `dt.Wort:` forces it, `unknownWord` stays for tokens that match neither. Slots: German-only (German lemma and/or `dt.` filters) and mixed (original side joined through `Elb1871GreekMapping`/`Elb1871HebrewMapping` to the German words). Measured: `Tempus:aor Modus:partizip dt.Verbform:finit` 1,478 words in 1,247 verses (Matt 1:20 first, German position 7), ~80 ms warm; `dt.Verbform:partizip` (no lemma) 17,862 words in 12,040 verses, ~140 ms; `Sohn dt.Numerus:plural` 1,234 words; `Liebe` 184 words in 172 verses; `agape Kasus:nom` 36 and `H1254 Stamm:qal` 39 unchanged. No migration, no new index needed (a seq scan of `Elb1871Morphology` is ~30 ms). Deviations:

- The German lemma is `Elb1871Morphology."Lemma"` (case-insensitive through the existing `lower("Lemma")` index), not `Elb1871Words."Lemma"`, which is empty on the dev database.
- `GrammarVocabularyKey` gained `germanOnly` (`Verbform`, `STTS`, `Wort` exist only after `dt.`) and `germanValues` (the German tag set differs: Präteritum, finit, Positiv, Hilfsverb, Determinativ, Zahlwort, Sonstiges); `GrammarSlotResponse` gained `germanLemma`; `GrammarMatch.original` is omitted for a German-only slot.
- `dt.Wortart:Determinativ` (alias `Artikel`) is UD `DET`, which holds articles and possessive/demonstrative determiners (STTS `ART`, `PPOSAT`, `PDAT` ...); `Konjunktion` is `CCONJ` and `SCONJ`; `Hilfsverb` (`AUX`) is separate from `Verb`.
- A German-only slot and an original slot are two different words even at the same Elb1871 position (`Liebe agape` hits Matt 24:12); the distinct-word rule uses a key across the three word tables.
- `totalWords` counts the German words of German-only slots; chapter `total` counts distinct matched words.
- Facets: `key=dt.Numerus` (or no key for a German-only slot) counts German words of `Elb1871Morphology` given the slot's German lemma and other `dt.` filters, response keys are prefixed `dt.`; original-key facets ignore the German side.
- Spot-check: `Geschlecht` of nouns is lexical and right (Welt f, Gott m, Leben n); `Numerus` of nouns follows the form (Söhne p, Tage p) but unmarked plurals are tagged singular ("die Himmel" in Gen 1:1); the determiners are the weak spot (plural `die` is tagged S/F, 974 plural of 108,616 DET; adjectives 485 of 9,122). Both stay enabled; combine with `dt.Wortart:Substantiv`. The lemma `Liebe` holds 27 verb forms ("ich liebe") that the tagger lemmatized as the noun.
