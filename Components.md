# Components

Registry of the shared UI components of the React frontend (`src/UnshackledWord.Web/src/components`). Agents: check this list before building anything and reuse or extend an entry (add a prop or variant) instead of creating a new component. Every new component is proposed in chat first, then added here with a one-line description. `bun run check:components` fails if a component file is missing from this table or if two components share a name.

Rules: design tokens only (Tailwind theme variables from `src/styles/index.css`), no hardcoded colors, spacing or font sizes, no raw `<button>`, no inline styles, no arbitrary Tailwind values.

| Component | Description |
| --- | --- |
| `Button` | The only button. Variants `primary` / `secondary` / `ghost` / `inline` (text flow, inherits font), sizes `sm` / `md`; defaults to `type="button"`; `aria-pressed="true"` on `secondary` shows the pressed (toggle) state. Accepts a `ref`. |
| `Switch` | Generic on/off switch (`role="switch"`, `aria-checked`): pill track with a knob that slides left (off) to right (on, accent track); inherits the surrounding font size, label/children vertically centred with the track, focus-visible ring, disabled state, no motion under `prefers-reduced-motion`. Geometry and colours in `.switch` / `.switch-track` / `.switch-knob` (`index.css`, tokens only). Props `checked`, `onCheckedChange(checked)`, optional children as label, plus button attributes. Used for the line-kind toggles of the compare legend in `MappingEditor`. |
| `ThemeToggle` | One icon button cycling system / light / dark, persisted in localStorage. |
| `LanguageSwitch` | One button toggling between DE and EN (i18next), shows the current language, persisted in localStorage. |
| `AppShell` | Page frame: header with brand, language and theme controls, plus the routed `<Outlet />`; "Lemmata bearbeiten" nav link when logged in (md+); a route with `handle: { layout: "fill" }` gets the full-height layout (page does not scroll from md, content fills the height). |
| `BibleChapterPicker` | OT/NT bar that unrolls a book grid with chapter links (Psalms split in five books); props `books`, `currentBookId`, `currentChapter`, `defaultTestament`, `chapterHref(ref)` (link target, default the reader). |
| `WordDetailPopover` | Pop-up with the Greek/Hebrew readings of one Elberfelder word (native popover; anchored on desktop, bottom sheet on mobile); shows TSK cross references of the verse (collapsible, linked), mapping provenance badge (AI suggestion / confirmed / manual), words translated together, uncertainty hints and an edit-mapping action (disabled until `onEditMapping` is passed); props `word`, `status`, `detail`, `books`, `isSample`, `onRetry`, `onClose`, `onEditMapping`. The TSK list is a `CrossReferenceList variant="details"`. |
| `MappingEditor` | Inline editor below a verse to correct the German - original word mapping (drag and drop or select-then-tap, group badges, undo, diff summary, Save/Cancel; read-only when editing is disabled); props `data`, `reference`, `saving`, `saveError`, `onSave(links, { clearParts })`, `onCancel`; optional `review` word-id sets add a "prüfen" marker (revision carry-over). Compound words (roadmap 0016.10f): stored parts (`partOrder` / `germanWordPart`, `Gerstenernte` = `Gersten` + `ernte`) are drawn as joined tiles with node keys `g12.1` / `g12.2` and linked on their own; `partsEditable` (Elb1871 data, false for revision variants) adds "Teilung aufheben" on a part; the client mirrors the server's part rules (at least two parts, every part linked, at most 30 characters, no parts on an added word, the parts spell the word) as `FormError`s that block Save; `onSave` passes `clearParts: true` when the save removes stored parts (with a visible note). `onAiRedo` shows the "KI neu zuordnen" action (only passed for Admin/Maintainer on Elb1871 data). With `partsEditable`, a selected whole German word of two or more letters (not added, not split) gets "Wort teilen …", which opens the `WordSplitter` inline; "Teilen" splits the word (`splitWord`, its old links drop) and selects the first part. Review of an agent proposal (roadmap 0016.7f): `mode="compare"` shows `compareLinks` against `data.links` read-only (new links solid in the ok tone, links that go away dashed in the error tone, shared links neutral, all lines drawn at once, legend neu / entfällt / unverändert, change list from `diffStates`, proposed parts as joined tiles; no editing, no save row, no focus grab, no `data-mapping-editor`, so the review keys keep working); `footer` renders the review actions there, and in edit mode extra content above the buttons (the lemma table of an edit-merge). `initialLinks` (edit mode) starts the editor from the proposal while the change list and the word status still compare with `data.links`; Save is then offered even when both are equal; `saveLabel` replaces the "Speichern (n)" text ("Bearbeitet übernehmen"). Pure state in `lib/bible/mappingEditor.ts` (`compareStates`, `partsFromCuts`, `toggleCut`). Pure state and part rules in `lib/bible/mappingEditor.ts` (`splits`, `splitWord`, `unsplit`, `partIssues`, `partsToClear`). Link roles (roadmap 0018.2f): each link chip has a Kern/Formteil toggle (`aria-pressed`; key U on a selected German tile toggles all its links), a unit link is drawn as a muted dotted line and its German tile muted (`MappingToken` `unit`); a Hebrew link to a word with several morphemes gets a `Select` of the morphemes (original · gloss (Strong's), main marked ★); a selected part tile gets a part lemma `TextField` (one undo step on blur/Enter). Saves send the legacy payload unless `needsRoleFields` (role data loaded or set in this session); then every link carries `role` and the editor lists the server's role checks (several heads with an "Mehrere Kerne zulassen" action, units without head). `saveErrorDetails` (messages of a 400) are listed under the error with word ids replaced by the words. Pure state in `lib/bible/mappingEditor.ts` (`roles`, `partLemmas`, `setRole`, `setMorpheme`, `setMultiHead`, `setPartLemma`, `roleIssues`, `needsRoleFields`, `readableServerError`). A collapsible "Rollen und Begriffe erklärt" panel (native `details`, keys `bible.mapping.roles.help.*`) below the legend explains head, unit (Formteil), several heads, added word, morpheme, word part and unmapped with examples. |
