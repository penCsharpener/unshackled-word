# Components

Registry of the shared UI components of the React frontend (`src/UnshackledWord.Web/src/components`). Agents: check this list before building anything and reuse or extend an entry (add a prop or variant) instead of creating a new component. Every new component is proposed in chat first, then added here with a one-line description. `bun run check:components` fails if a component file is missing from this table or if two components share a name.

Rules: design tokens only (Tailwind theme variables from `src/styles/index.css`), no hardcoded colors, spacing or font sizes, no raw `<button>`, no inline styles, no arbitrary Tailwind values.

| Component | Description |
| --- | --- |
| `Button` | The only button. Variants `primary` / `secondary` / `ghost` / `inline` (text flow, inherits font), sizes `sm` / `md`; defaults to `type="button"`; `aria-pressed="true"` on `secondary` shows the pressed (toggle) state. Accepts a `ref`. |
| `ThemeToggle` | One icon button cycling system / light / dark, persisted in localStorage. |
| `LanguageSwitch` | DE / EN switch (i18next), persisted in localStorage. |
| `AppShell` | Page frame: header with brand, language and theme controls, plus the routed `<Outlet />`; "Lemmata bearbeiten" nav link when logged in (md+); a route with `handle: { layout: "fill" }` gets the full-height layout (page does not scroll from md, content fills the height). |
| `BibleChapterPicker` | OT/NT bar that unrolls a book grid with chapter links (Psalms split in five books); props `books`, `currentBookId`, `currentChapter`, `defaultTestament`, `chapterHref(ref)` (link target, default the reader). |
| `WordDetailPopover` | Pop-up with the Greek/Hebrew readings of one Elberfelder word (native popover; anchored on desktop, bottom sheet on mobile); shows TSK cross references of the verse (collapsible, linked), mapping provenance badge (AI suggestion / confirmed / manual), words translated together, uncertainty hints and an edit-mapping action (disabled until `onEditMapping` is passed); props `word`, `status`, `detail`, `books`, `isSample`, `onRetry`, `onClose`, `onEditMapping`. The TSK list is a `CrossReferenceList variant="details"`. |
| `MappingEditor` | Inline editor below a verse to correct the German - original word mapping (drag and drop or select-then-tap, group badges, undo, diff summary, Save/Cancel; read-only when editing is disabled); props `data`, `reference`, `saving`, `saveError`, `onSave`, `onCancel`.; optional `review` word-id sets add a "prüfen" marker (revision carry-over). |
| `HeaderWordInfo` | Centre of the sticky top menu: original word, lemma, Strong's and decoded morphology of the hovered word (fed through `lib/headerInfo`). |
| `WordInfoCard` | Hover info (original, lemma, Strong's, morphology) as a small box in the reader's page margin from 1024px; exported from `HeaderWordInfo.tsx`. |
| `MarginStack` | Column of cards in the reader's right margin next to the text, level with a verse and pushed up near the chapter end; props `verse`, `colRef`. |
| `HeaderPickerBar` | Wraps the chapter picker and level slider: rendered into the header's slot from 1200px (one slim menu row), a sticky bar under the header below. |
| `OriginalVerse` | Plain original-language text of one verse (no transliteration) with optional Strong's / morphology per word; props `data`, `reference`, `showLemma`, `showStrongs`, `showMorphology`, `onToggleLemma`, `onToggleStrongs`, `onToggleMorphology`. `variant="margin"` is the side-panel form: no frame and toggles, 'text-lg', every word a link to its Strong's page (`/bible/strongs/{id}`), `data` only needs `language` + `originalWords`. |
| `CrossReferenceList` | TSK targets as links to the verse (`/bible/{book}/{chapter}#v{verse}`), abbreviated book name as text and the full name as `aria-label`; props `references`, `books`, `variant` (`details`: collapsible list with count heading for the word box, `truncated` note; `inline`: wrapping links separated by middots for the side panel and the eye panel, one Tab stop with arrow keys / Home / End moving between the links), `truncated`. |
| `VerseSidePanel` | Panel next to one verse in the left margin from 120rem (`.verse-side` CSS: the verse row is a one-cell grid, the panel shares the cell so it lines up with its verse); props `mode`, `label`, `expanded`, `onExpandedChange`, `children`. `tsk` is out of flow, clipped to whole lines of the verse height with a "+N" button that opens the full list as an overlay (also on focus inside, closes on `Esc`, outside click, focus leaving); `original` stays in flow so the row grows to the taller of German and original and nothing is cut off. One shared `ResizeObserver` measures all panels. |
| `MappingToken` | One word tile of the mapping editor (German or original) with group badge, status, selection and drag/drop handlers; built on `Button`. Optional `review` text draws a "prüfen" note under the word. |
| `Select` | Labelled native select styled with tokens; props `label`, `value`, `onChange(value)`, `options` (`{ value, label, disabled?, title? }`), `disabled`, `size` (`sm` / `md`), `labelHidden` (sr-only label, e.g. in a cell editor), `invalid`, `selectRef`, `onBlur`, `onKeyDown`. |
| `EmptyState` | Dashed placeholder box; props `title`, `children`, `variant` (`empty` / `comingSoon` adds hidden skeleton rows), `skeletonRows`. |
| `BookBarChart` | Occurrences per Bible book as SVG columns (list view on narrow containers, list/chart toggle from 40rem), bars coloured by the 8 Bible sections with legend, zeros muted, text alternative per book; props `books`, `counts`, `testaments`, `title`, `summary`, `selectedBookId`, `onSelectBook(bookId \| null)`, `defaultView`. |
| `DonutChart` | Ring chart with legend (count and percent per slice), screen-reader table, optional filter `Select`; more than 8 slices fold into "Other"; props `title`, `subtitle`, `note`, `slices` (`{ key, label, text?, value, highlight? }`), `centerValue`, `centerLabel`, `activeKey`, `onSelectSlice(key \| null)`, `filterLabel`. `sliceHref(key)` + `onSliceNavigate` turn the legend entries into router links (e.g. to the Strong's page; then no hidden table, the list is not `aria-hidden`). |
| `StrongsStatsHeader` | Top of the Strong's page: heading with lemma and glosses, stat line, "formed from" placeholder, occurrences per book (`BookBarChart`) and translation donuts (`DonutChart`: renderings, plus the Strong's numbers behind the selected rendering in OT and NT); loads its own data (`lib/bible/strongsStats`), shows loading/error with retry/empty states; props `strongs`, `bookId`, `rendering`, `onSelectBook`, `onSelectRendering` (bar and slice clicks drive the concordance filters). |
| `AuthCard` | Centered bordered card with the page's `h1` title for the auth pages; props `title`, `children`. |
| `TextField` | Labelled text/email/password input (`multiline` + `rows` render a textarea) styled with tokens (required by default); props `label`, `value`, `onChange(value)`, `size` (`sm` / `md`), `labelHidden`, `invalid`, `inputRef` plus native input attributes. `type="search"` shows a leading magnifier (or any `icon`, which fits other types as well). |
| `FormError` | Inline `role="alert"` message for forms; renders nothing for an empty `message`. |
| `UserMenu` | Header slot driven by `useAuth`: "Sign in" link-button when logged out, otherwise an avatar button with a menu (passkeys, "Lemmata bearbeiten", data quality, maintenance for maintainer/admin, invitations for admins, sign out). |
| `PasskeyManager` | Lists, adds (native WebAuthn) and deletes the signed-in user's passkeys; hides itself behind an "unsupported" note without WebAuthn. |
| `InviteCodeManager` | Admin invitation codes: create form, table (code, status, seats used/total, expiry, note), copy registration link, two-step revoke. |
| `MorphologyGrid` | Lemma editor table: div-based ARIA grid (sticky header, verse and word columns, virtualized with `@tanstack/react-virtual`, dropdown columns as wide as their longest label), active-cell editors, spreadsheet keyboard map (arrows, Enter/F2, Tab between editable cells, type-to-pick, Delete, Esc, Ctrl+S), dirty / invalid / missing rendering; one card per word below 48rem; props `words`, `edits`, `labels`, `rules`, `stts` (optional `SttsHelper`: filters the STTS dropdown by the row's UD tag with a "show all" entry, flags a non-fitting tag and offers the proposed one as a button that only acts on click), `hiddenColumns`, `readOnly`, `lemmaSuggestions`, `onEdit(word, field, value)`, `onResetRow`, `onActiveWordChange`, `onSave`, `headerActions` (mouse-only controls inside a column header, e.g. the bulk-edit pencil). |
| `SaveBar` | Sticky pending-changes bar: count, hint, Discard with inline confirm, primary save, saving / saved / error messages (texts from `lemmas.save.*`); props `count`, `status`, `message`, `savedCount`, `hint`, `saveLabel`, `disabled`, `onSave`, `onDiscard`. |
| `ToggleMenu` | Button with a popover list of checkboxes (e.g. column visibility) and optional reset; props `label`, `items` (`{ key, label, checked, disabled? }`), `onChange(key, checked)`, `onReset`, `resetLabel`. |
| `Dialog` | Generic modal on the native `<dialog>` (focus trap, inert page, Esc, backdrop click, focus return; full screen below 48rem); props `open`, `onClose`, `title`, `description` (also the accessible description, e.g. a step line), `size` (`md` / `lg`), `initialFocusRef`, `footer`, `dismissible` (false blocks Esc/backdrop/close while a request runs), `bare` (body without padding for self-scrolling content). Renders its content only while open. `placement="top"` docks it near the top edge from md (palette); `titleHidden` keeps the title for assistive tech only and drops the header row to the close button. |
| `LemmaBulkEdit` | Bulk lemma replace dialog (three steps Suchen / Prüfen / Fertig in one `Dialog`): several source lemmas as chips with live counts, target lemma check, part-of-speech and scope filters; paged review list (50/100/250/500, virtualized with `@tanstack/react-virtual`) grouped by form with tri-state group checkboxes, ±5-word context, old → new, verse on demand, selection across pages, apply with explicit word ids, 409 stale handling, undo of the last change set; blocked while the grid has unsaved edits. Original-language guard: an "Original" filter in the search step, a Form / Original grouping switch (automatically Original when the server flags the lemma as ambiguous), two-level original > form groups with tri-state checkboxes, the original word + Strong's + a mapping link per row, flagged groups (other meaning, part of speech differs, added / unmapped) deselected by default, the expected original sent with every id, 409 reasons per row, and "set another lemma" for the groups left out. Dialog, step, search and paging live in the URL search params (`dlg`, `from`, `to`, `orig`, `grp`, `scope`, `page`, `size` …); logic in `lib/lemmas/bulk.ts`. Props `initialFrom`, `bookId`, `chapter`, `books`, `partOfSpeechOptions`, `dirtyCount`, `onSaveGrid`, `onApplied`. |
| `StatTile` | Overview card of one number: `code`, `title`, big `value`, `sub` line (from the container's `@2xl`), `delta` text (no colour judgement), `severity` (`error` / `warning` / `info` / `ok`) shown as icon + `severityLabel` + left border token, never colour alone; a link (`href`), a toggle button (`onSelect`, `selected` sets `aria-pressed`) or a plain card; `loading` renders a skeleton. |
| `RankedBarList` | Ordered list of horizontal bars (`<ol>`; bar is `aria-hidden`, value and share are text); items `{ key, label, sub, value, share, flags, muted, selectable }`; label is a button with `onSelect`, `selectedKey` highlights, `max` rows then "Show more", `renderExpanded` + `expandLabel` add a per-row expander for details, `valueFormat`. |
| `CoverageHeatmap` | Grid of heat-coloured `Button` cells (`--uw-heat-0..5`), one tab stop with arrow-key navigation; rows `{ key, label, cells: { key, label, value, total, title } }`, `mode` `share` (value / total) or `count`, `scale` (lower bounds of levels 1-5), optional `columns` header (matrices), `showLabels`, `outlined(row, cell)`, `selected`, `onSelectCell`, `legend`; every cell has a title and an `sr-only` table lists all values. Used for chapter coverage and the M3 / L5 matrices. |
| `FindingsTable` | Paged list of data-quality findings (reference, German word with inline +-5-word context, original + Strong's + gloss, reason with "already fixed?" badge, severity as icon + text) as a table from the container's `@2xl`, cards below; `columns` subset (`ref`, `german`, `original`, `stts`, `pos`, `detail`, `severity`), `jumps(finding)` per-row buttons (`href` opens in a new tab with an sr-only hint, `onClick` for same-page actions), pager with previous / next and optional page-size select (`onPageSize`), `loading` / `error` + `onRetry` / `emptyText`. Props `findings`, `total`, `page`, `pageSize`, `onPage`, `books`. |
| `SearchOverlay` | Search palette over the reader (opened by the magnifier in `AppShell` or `F`): `Dialog` (`placement="top"`, `titleHidden`) with a search `TextField`, ranked verse hits (`VerseHitList`) with the lemma-widening lines, hits per book (`BookBarChart`, click filters, removable chip) and, per query word, the originals as `DonutChart` (legend links to the Strong's page; very frequent words collapsed behind "Trotzdem anzeigen"); two columns from `lg`, tabs Verse / Grundtext below; debounce 300 ms / min 2 characters, arrow keys + Enter through the hits. Searches at the reader level (`useReaderLevel`): revised wording is matched and shown, revised hits get the left border. Props `open`, `onClose`. |
| `VerseHitList` | Listbox of verse hits (`<ol role="listbox">` of links to `/bible/{b}/{c}#v{v}`): reference in the reader language, verse text with `matched` words in `<mark>`, "Mehr laden" button. Props `hits`, `books`, `language`, `activeIndex`, `revisedLabel(level)` (optional; hits with `revised` get the accent left border and this title), `onSelect(hit)` (plain click, caller navigates), `onLoadMore`, `hasMore`, `loading`, `id`, `label`; option ids via `hitOptionId(id, index)` for `aria-activedescendant`. |
| `LevelSlider` | Compact range slider over translation levels (`levels: { level, name }[]`, `value` = level, `onChange(level)`, `label`): one stop per preset evenly spaced by index, no number shown, level name as `title` and `aria-valuetext`, arrow keys/Home/End; renders nothing with fewer than two levels. Moving it flashes the selected level name in an `<output>` below for 1.5 s. Native `<input type="range">` with `accent-accent`. |
| `BulkReplaceTable` | Hit list of the bulk word replace (roadmap 0013): one card per hit with a checkbox (`checked` set of `hebRefId:occurrence` keys, `onToggle`), reader link (`referenceOf`, `pathOf`), Strong's/lemma chips, the excerpt with the hit marked, hints (article before, target version, differs from source, reviewed). Not virtualised (max 1000 rows). |
| `VersionHistory` | Collapsed `<details>` list of revision versions (newest first, `versions: { version, text, createdAt, createdBy?, note?, endedAt? }[]`) with a client-side word diff against the previous version (`lib/revision/wordDiff`; added in `<ins>`, removed struck through), author/date, note, per-version "wiederherstellen" (`onRestore(text)`) and, if `canRemove`, "Revision dieser Stufe entfernen" behind a confirm `Dialog` (`onRemove`). |
| `RevisionEditor` | Panel below a verse (pen icon in `ChapterPage`, Admin/Maintainer only) to write a new version of the verse at a revision level: level `Select` (presets except base 100), multi-line `TextField` prefilled with the active variant or the Elb1871 text, optional note, save/cancel, saved confirmation with version, 409 conflict message with reload; level `Select` lists levels with a variant first ("Revision · v3") plus "Neue Stufe …" (adds a preset through `pages/RevisionLevelDialog`), a second `Select` "Ausgangstext" (Elb1871 or an existing variant; refills the field after a confirm `Dialog` when it was edited; the choice is sent as `basedOnLevel`), collapsed `VersionHistory` with restore (prefills the field) and "Revision dieser Stufe entfernen"; props `verseRef`, `reference`, `onClose`. Uses `lib/revision`. |
